# SLAI CORE

Локальная система аудита внешнеэкономических сделок.

## Запуск

1. Установи Ollama и запусти модель.
2. Установи зависимости:
   pip install -r requirements.txt
3. Запусти сервер:
   python slai_server.py
4. Открой интерфейс:
   http://127.0.0.1:8080/index.html
